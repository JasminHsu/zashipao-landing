# 雜事房 Key Vision

版本：01  
方向：溫暖、俐落的共同工作室

## 核心感受

雜事房不是效率競賽，也不是熱鬧的社群聊天室。畫面應該讓人感覺可以安心坐下來，和幾個人一起開始，各自完成眼前的一件事。

- 溫暖，但不使用大量米色裝飾。
- 俐落，但不顯得冷硬或像企業後台。
- 有陪伴感，但不靠虛構人數、見證或成果數字。
- 有品牌個性，但操作頁仍以清楚、安靜、可重複使用為主。

## 色彩

| 角色 | Token | 色碼 | 用途 |
| --- | --- | --- | --- |
| 紙張白 | `paper` | `#FFFDF8` | 主要頁面與卡片背景 |
| 暖灰白 | `cream` | `#FAF7F2` | 次要區塊、輸入欄與分區背景 |
| 墨黑 | `ink` | `#1C1917` | 標題、內文與深色空間 |
| 亮橘 | `terracotta` | `#FF5A36` | 主要 CTA、焦點與少量重點 |
| 森林綠 | `forest` | `#4A7260` | 成功、在線、專注與次要操作 |
| 邊線 | `border` | `#DDD6CB` | 分隔線、輸入框與卡片邊界 |

規則：

- 亮橘保留品牌辨識度，不改成暗陶土色；只用於主要操作與重點，不做大面積背景。
- 頁面以暖白和暖灰白交替，不再混入淺藍、亮黃等大面積裝飾色。
- 森林綠只代表穩定、成功、在線或次要操作，不和亮橘爭奪主要 CTA。

## 字體

- Logo：`Noto Serif TC`，保留品牌識別。
- 頁面標題、區塊標題、按鈕與介面：`Noto Sans TC`。
- 內文：`Noto Sans TC`。
- 不使用負字距；操作頁不使用超大型展示字。

## 形狀與間距

- 一般按鈕、輸入框、卡片與選單：`8px` 圓角。
- 膠囊形只用於狀態、標籤、分段控制與進度步驟。
- 卡片使用細邊框；陰影只在浮層、帳號選單和需要層級的主要面板使用。
- 同一頁面只保留一個最明顯的主要操作。

## 共用元件

### 主要按鈕

- 亮橘背景、墨黑文字、8px 圓角。
- 用於「免費加入」「預約這場」「確認預約」等主要下一步。

### 次要按鈕

- 透明或紙張白背景、深色邊框、墨黑文字、8px 圓角。
- 用於查看、返回、加入行事曆等操作。

### 狀態

- 綠色：完成、已預約、在線、專注中。
- 橘色：目前步驟、需要注意或主要下一步。
- 狀態可以使用膠囊形，但操作按鈕不因而全部變成膠囊。

### 卡片與表單

- 紙張白背景、`border` 邊線、8px 圓角。
- 輸入欄使用暖灰白底；focus 必須清楚可見。
- 不在卡片內再堆疊裝飾性卡片。

## 頁面節奏

### Landing Page

1. 第一屏：品牌、核心價值與主要 CTA。
2. 痛點與價值：三個簡短理由。
3. 近期場次：直接看到可採取的下一步。
4. 信任資訊：只使用可驗證的規則與已獲授權的真實回饋。
5. FAQ 與最後 CTA。

### 產品內頁

- 使用相同暖白背景、黑體標題、橘色主要 CTA、綠色狀態與 8px 元件圓角。
- 導覽、頁面標題、主要工作區的順序固定。
- 預約、待辦與已預約場次應看起來屬於同一個產品。

### 專注房間

- 房間可以改為深色，但沿用同一個亮橘、森林綠、字體與控制規則。
- 深色只服務專注與視訊情境，不另外建立一套品牌。

## 不採用

- 不把全部標題改成宋體。
- 不把亮橘全面改成 `#C45F38`。
- 不把所有按鈕做成膠囊。
- 不加入漸層、光暈、條紋、裝飾球或無功能的插畫。
- 不使用虛構使用人數、完成數、客戶 Logo 或未授權見證。

## 實作檢查

- 390、768、1024、1440px 不溢出或遮擋。
- 所有主要操作有一致且可見的 `focus-visible`。
- 動畫尊重 `prefers-reduced-motion`。
- 新元件優先使用現有 Tailwind token，不另外寫近似色碼。
- 修改完成後至少檢查首頁、登入、場次、預約、待辦、已預約、等候區與房間。
