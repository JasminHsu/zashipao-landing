## 首頁與產品內頁視覺統一

- 狀態：功能流程穩定後安排，不阻擋目前視訊房與預約功能上線。
- 背景：首頁以亮珊瑚橘、白色和較強的編輯式版面為主；預約、待辦與場次內頁多使用暖米色、森林綠和卡片式介面，因此看起來像兩套產品。
- 參考方向：以現有 `paper`／`cream`、`forest`、`terracotta` 與 `ink` token 建立同一套層級。保留首頁較亮、俐落的辨識度，不直接照搬外部建議的 `#C45F38`，也不把全站改成單一暖色。
- 修改範圍：頁面背景與留白、標題／內文字體層級、主次 CTA、卡片圓角、漢堡選單，以及房間元件中仍直接寫死的色碼。
- 實作原則：先整理共用 design tokens 和元件規則，再逐頁套用；避免只替換色碼造成對比不足或破壞首頁視覺。
- 驗收：首頁、註冊登入、場次、預約、待辦、已預約場次、等候區與視訊房並排檢查；確認主按鈕、背景、標題與選單屬於同一品牌，並通過文字對比、鍵盤 focus 及 390／768／1024／1440 px 響應式檢查。
